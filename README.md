#  Password Manager

##  Requirements
- `pip install tabulate`

##  Info

Project for school. A simple Password Manager in python to showcase pythons ability to manipulate files, and handling data.

This is not meant to be a real Password Manager. The passwords are saved in PLAINTEXT so it is not secure!

The hangman was my friend's idea, to jolly up the code a bit.

The code so far is as complete as i need it to be.
